# Multi-Agent AI Career Copilot

## Overview
AI system that analyzes resumes, matches jobs, generates interview questions, and provides learning recommendations using multiple AI agents.

## Features
- Resume Analysis
- Job Matching
- AI Interview Questions
- Learning Roadmap
- RAG-based Q&A

## Tech Stack
- Python
- CrewAI
- LangChain
- FAISS
- FastAPI
- Streamlit
